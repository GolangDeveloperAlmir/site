# Contributing

Thanks for your interest in improving the site! To get started:

1. Fork the repository and create a branch.
2. Run `yarn install` and `yarn dev` to start the site locally.
3. The install step configures a pre-push hook that runs `yarn verify` (lint, type-check, tests, build). You can also run it manually with `yarn verify` or `make ci` before pushing.
4. Follow the [commit message template](../.github/commit_template.md) and open a pull request.

If you have questions or ideas, feel free to open an issue.
